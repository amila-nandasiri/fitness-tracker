# Fitness Tracker

A single-page personal fitness tracker: daily checklist, weight and tape
measurements, a 5-day workout plan with set logging, and progress charts.

- No build step. `index.html` is the whole app.
- Data is stored in the browser. Optional sync writes one JSON file to a
  private GitHub repository of your choice (set up under Settings).
- Exercise photos come from [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).

To publish: Settings → Pages → Deploy from a branch → `main`.
